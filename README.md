One sentence, at most 200 characters, pitching a bizarre startup idea that sounds absurd until you realise it would actually sell. Built for the [make.fun](https://make.fun/c/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a) bounty "Ridiculous at First Glance, Real by the Second".

The program writes the pitch to `/output/entry.txt`:

> We rent professional mourners for dead houseplants: a trained griever holds a tiny funeral for your fern, and the guilty owner pays $40 for closure instead of quietly buying a replacement.

Run it with Node 22+:

```sh
node main.ts
```
